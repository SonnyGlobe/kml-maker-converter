Overview

The Ortiz KML Creator is an advanced yet user-friendly web-based application designed to facilitate the generation of Keyhole Markup Language (KML) files. This tool allows users to transform raw geospatial data from CSV files into structured KML files, making it easier to visualize geographic locations on platforms such as Google Earth, Google Maps, and GIS applications.

By offering flexible configuration options, the KML Creator ensures that users can generate KML files tailored to their specific needs, whether working with point-based locations, radius-based coverage areas, or complex polygonal boundaries.

Key Features

1. User-Friendly Interface

  • Well-structured, easy-to-navigate layout.
  • Clear input fields and selection menus for seamless configuration.
  • Quick file selection and upload functionality.

2. Flexible KML Structure

  • Supports different KML structures:
    • Points - Converts latitude-longitude pairs into precise markers.
    • Radius - Creates circular coverage areas for geospatial analysis.
    • Polygon - Defines complex boundary shapes using multiple coordinate points.
  • Option to organize KML data into structured folders for better management.

3. CSV File Upload and Processing

  • Users can upload a CSV file containing geospatial data.
  • Displays the selected file name for easy confirmation before processing.
  • Supports multiple coordinate formats for better compatibility.

4. KML File Generation

  • Processes the uploaded CSV file based on user-defined settings.
  • Automatically converts data into a structured KML format.
  • Ensures high compatibility with Google Earth and other KML-supported platforms.

5. Efficient Data Handling

  • Validates input data to prevent errors and inconsistencies.
  • Ensures accurate conversion of coordinates into KML Placemark, Polygon, or Circle elements.
  • Handles large datasets efficiently while maintaining optimal performance.

Instructions for Using Ortiz KML Creator

Follow the steps below to generate your KML or GeoJSON file:

  1. Upload CSV File:
    Upload your CSV file using the “Choose File” button. Make sure your CSV contains headers like latitude, longitude, radius (for circles), or polygon (for shapes).
  2. Main Tag:
    Enter the name of the CSV column that should serve as the identity for each KML entry (e.g., Location Name).
  3. Folder Structure:
    Input a comma-separated list of fields (e.g., City,Country) to group your data into folders.
  4. Map Type:
    Choose how to display the data: Points, Radius, or Polygon.
    • Points: Display as map markers.
    • Radius: Circle areas using values from the radius column.
    • Polygon: Closed shapes based on coordinate paths in the polygon column.
  5. Export Type:
    Select your output format: either KML or GeoJSON.
  6. Icon Style:
    Select an icon for point markers (applies only for Map Type = Points).
  7. Line Width: Adjust thickness from 1 to 10 units.
  8. Line Color: Use the color selector for border color of radius and polygons.
  9. Fill Color:
    Use the color picker to choose the fill color for radius and polygon areas.
  10. Opacity:
    Set opacity level (0% = transparent, 100% = opaque) for your fill color.
  11. Circle Smoothness: The smoothness of the radius is fixed at 50.

Important Notes:

  • Auto-Detection: The app auto-detects latitude, longitude, radius (for circles), and polygon (for shapes) from your CSV headers.
  • Default Radius: If no radius column is found, a default radius of 500 meters is applied.
  • Ensure Clean Data: Avoid extra spaces and formatting issues in your CSV headers and values for best results.

CSV Format Requirements

  • Ensure your CSV file doesn’t contain blank rows
  • Best used with comma-delimited CSVs
