Overview

TheOrtiz KML Creatoris an advanced yet user-friendly web-based application designed to facilitate the generation ofKeyhole Markup Language (KML)files. This tool allows users to transform raw geospatial data fromCSV filesinto structured KML files, making it easier to visualize geographic locations on platforms such asGoogle Earth, Google Maps, and GIS applications.

By offering flexible configuration options, the KML Creator ensures that users can generate KML files tailored to their specific needs, whether working withpoint-based locations, radius-based coverage areas, or complex polygonal boundaries.

  • Well-structured, easy-to-navigate layout.

3. CSV File Upload and Processing

Instructions for Using Ortiz KML Creator

Follow the steps below to generate your KML or GeoJSON file:

  1. Upload CSV File:
    Upload your CSV file using the “Choose File” button. Make sure your CSV contains headers likelatitude,longitude,radius(for circles), orpolygon(for shapes).
  2. Main Tag:
    Enter the name of the CSV column that should serve as the identity for each KML entry (e.g.,Location Name).
  3. Folder Structure:
    Input a comma-separated list of fields (e.g.,City,Country) to group your data into folders.
  4. Map Type:
    Choose how to display the data:Points,Radius, orPolygon.
    • Points:Display as map markers.
    • Radius:Circle areas using values from theradiuscolumn.
    • Polygon:Closed shapes based on coordinate paths in thepolygoncolumn.
  5. Export Type:
    Select your output format: eitherKMLorGeoJSON.
  6. Icon Style:
    Select an icon for point markers (applies only for Map Type = Points).
  7. Line Width:Adjust thickness from 1 to 10 units.
  8. Line Color:Use the color selector for border color of radius and polygons.
  9. Fill Color:
    Use the color picker to choose the fill color for radius and polygon areas.
  10. Opacity:
    Set opacity level (0% = transparent, 100% = opaque) for your fill color.
  11. Circle Smoothness:Thesmoothnessof the radius is fixed at50.

Important Notes:

  • Auto-Detection:The app auto-detectslatitude,longitude,radius(for circles), andpolygon(for shapes) from your CSV headers.
  • Default Radius:If noradiuscolumn is found, a default radius of500 metersis applied.
  • Ensure Clean Data:Avoid extra spaces and formatting issues in your CSV headers and values for best results.

CSV Format Requirements

  • Ensure your CSV file doesn’t contain blank rows
  • Best used with comma-delimited CSVs
